## Compatibility notes

* Python 3.15 is supported and wheels created [GH-48172](https://github.com/apache/arrow/issues/48172).
* Python 3.10 support dropped [GH-50410](https://github.com/apache/arrow/issues/50410).
* Support for pandas < 2.0.0 dropped [GH-48808](https://github.com/apache/arrow/issues/48808).
* We now require numpy 2.x [GH-48473](https://github.com/apache/arrow/issues/48473).

## New features

* Conversion from numpy `StringDtype` to Arrow `string` (also `large_string` or `string_view`) is added [GH-51652](https://github.com/apache/arrow/issues/51652).
* DLPack implementation is now complete with the ability for Arrow Arrays, Tensors [GH-39295](https://github.com/apache/arrow/issues/39295) and `FixedShapeTensorArray`/`FixedShapeTensorScalar` [GH-38868](https://github.com/apache/arrow/issues/38868) to consume objects implementing this protocol. Also the protocol version has been updated to use version 1.3 [GH-41670](https://github.com/apache/arrow/issues/41670).
* `record_batch_reader_source` Acero node (`RecordBatchReaderSourceNodeOptions`) is exposed [GH-50801](https://github.com/apache/arrow/issues/50801).
* `search_sorted` kernel for all primitive types and run-end encoded arrays is available [GH-49677](https://github.com/apache/arrow/issues/49677).
* `RecordBatchFileReader.count_rows()` binding is added [GH-49305](https://github.com/apache/arrow/issues/49305).
* ` List`, `ListView`, `LargeList`, `LargeListView`, `Map`, `FixedSizeList` and `Struct` values are supported in the `run_end_encode` and the `run_end_decode` paths [GH-44183](https://github.com/apache/arrow/issues/44183).
* `eol` and `null_string` csv `WriteOptions` have been exposed [GH-34577](https://github.com/apache/arrow/issues/34577).

## Other improvements

* `.slice` methods accept Arrow intger scalars [GH-51145](https://github.com/apache/arrow/issues/51145).
* `arrow_to_pandas` `DateOffset` handling for nanoseconds/milliseconds is simplified [GH-50464](https://github.com/apache/arrow/issues/50464).
* First step towards abi3 wheels support for pyarrow has been merged [GH-50431](https://github.com/apache/arrow/issues/50431).
* `is_nested` now uses C++ type traits [GH-40282](https://github.com/apache/arrow/issues/40282).

## Relevant bug fixes

* UUID extension type round-trip to pandas returning bytes is fixed[GH-50312](https://github.com/apache/arrow/issues/50312).
* Scalar arithmetic dunders now return `NotImplemented` instead of raising `TypeError` when the other operand is not a recognized Arrow/NumPy type [GH-49826](https://github.com/apache/arrow/issues/49826).
* Raise instead of crashing on unopened `MemoryMappedFile().resize()` [GH-51229](https://github.com/apache/arrow/issues/51229).
* Writer options are synced between `write_table` and `write_to_dataset`/`ParquetFileFormat.make_write_options(...)` [GH-51220](https://github.com/apache/arrow/issues/51220).
* `BufferReader.readinto()` segfaults on a read-only destination are fixed [GH-51044](https://github.com/apache/arrow/issues/51044).
* `FunctionOptions.deserialize()` segfaults on non-buffer arguments are fixed [GH-51041](https://github.com/apache/arrow/issues/51041).
* Correct type of `ParquetLogicalType` is now returned for Geometry/Geography [GH-50849](https://github.com/apache/arrow/issues/50849).
* `pa.types.is_nested()` now returns `True` for run-end encoded types [GH-50847](https://github.com/apache/arrow/issues/50847).
* The reference cycle between the C++ FlightServerBase and the Python object now breaks to avoid leaking server [GH-50684](https://github.com/apache/arrow/issues/50684).
* Reference in `ConvertToSequenceAndInferSize`is fixed when an iterator raises on array conversion [GH-50591](https://github.com/apache/arrow/issues/50591).
* `pa.Table.from_struct_array` failure on empty array is fixed [GH-48344](https://github.com/apache/arrow/issues/48344).
* Invalid operator error message in `pyarrow.parquet` is fixed [GH-47369](https://github.com/apache/arrow/issues/47369).
* Preserving leading zeros in `read_csv` is now better documented [GH-46853](https://github.com/apache/arrow/issues/46853).
* `write_dataset` with csv file format ignoring delimiter is fixed [GH-39961](https://github.com/apache/arrow/issues/39961).
* `pyarrow.array` silently rewriting dictionary types to use signed integers for indexes is fixed [GH-37476](https://github.com/apache/arrow/issues/37476).
* Extension types with list-based storage cast segfault is fixed [GH-37004](https://github.com/apache/arrow/issues/37004).

## R Notes

### Breaking changes

- `read_feather()` and `write_feather()` are deprecated in favour of `read_ipc_file()` and `write_ipc_file()`, and `format = "feather"` in `open_dataset()` and `write_dataset()` is deprecated in favour of `format = "ipc"` ([GH-49237](https://github.com/apache/arrow/issues/49237)).
- The long-deprecated `.data.frame` argument to `map_batches()` has been removed, and the planned change to `pull()` returning a `ChunkedArray` by default has been dropped, so `pull()` no longer warns ([GH-51655](https://github.com/apache/arrow/issues/51655)).

### New features

- Azure Blob Storage is now supported via the new `AzureFileSystem` class and `az_container()` helper, analogous to `S3FileSystem` and `s3_bucket()` (@marberts, [GH-32123](https://github.com/apache/arrow/issues/32123)).

### Minor improvements and fixes

- A number of dplyr fixes: variables sharing a name with a function such as `date` now work in verbs ([GH-39688](https://github.com/apache/arrow/issues/39688)), `if_else()` works with a bare `NA` branch alongside dates ([GH-38358](https://github.com/apache/arrow/issues/38358)), and `summarise()` after `arrange()` no longer errors ([GH-45373](https://github.com/apache/arrow/issues/45373)).
- Factors and integer types inside list columns are now unified across the whole column when reading in multiple batches ([GH-50514](https://github.com/apache/arrow/issues/50514)), and Parquet `float16` columns now read correctly ([GH-50378](https://github.com/apache/arrow/issues/50378)).

## R Notes

### Breaking changes

- `read_feather()` and `write_feather()` are deprecated in favour of `read_ipc_file()` and `write_ipc_file()`, and `format = "feather"` in `open_dataset()` and `write_dataset()` is deprecated in favour of `format = "ipc"` ([GH-49237](https://github.com/apache/arrow/issues/49237)).
- The long-deprecated `.data.frame` argument to `map_batches()` has been removed, and the planned change to `pull()` returning a `ChunkedArray` by default has been dropped, so `pull()` no longer warns ([GH-51655](https://github.com/apache/arrow/issues/51655)).

### New features

- Azure Blob Storage is now supported via the new `AzureFileSystem` class and `az_container()` helper, analogous to `S3FileSystem` and `s3_bucket()` (@marberts, [GH-32123](https://github.com/apache/arrow/issues/32123)).

### Minor improvements and fixes

- A number of dplyr fixes: variables sharing a name with a function such as `date` now work in verbs ([GH-39688](https://github.com/apache/arrow/issues/39688)), `if_else()` works with a bare `NA` branch alongside dates ([GH-38358](https://github.com/apache/arrow/issues/38358)), and `summarise()` after `arrange()` no longer errors ([GH-45373](https://github.com/apache/arrow/issues/45373)).
- Factors and integer types inside list columns are now unified across the whole column when reading in multiple batches ([GH-50514](https://github.com/apache/arrow/issues/50514)), and Parquet `float16` columns now read correctly ([GH-50378](https://github.com/apache/arrow/issues/50378)).


## Ruby and C GLib Notes

- Flight RPC: Fixed GC related problems: [GH-50401](https://github.com/apache/arrow/pull/50401)
- Apache Parquet: Added support for buffered reader properties: [GH-51277](https://github.com/apache/arrow/pull/51277)

### Ruby

- red-arrow-format: Added support for building Apache Arrow data from Ruby objects.
- red-arrow-format: Added support for comparing arrays.
- red-arrow-format: Added support for comparing types.
- red-arrow-format: Added support for getting Ruby objects from Apache Arrow data.

The Apache Arrow team is pleased to announce the [v20.0.0](https://github.com/apache/arrow-java/releases/tag/v20.0.0) release of Apache Arrow Java.

## Changelog

### What's Changed

#### Breaking Changes
* GH-1078: Upgrade minimum JDK version from 11 to 17 by @jbonofre in [#1079](https://github.com/apache/arrow-java/pull/1079)
* MINOR: Restrict trigger push branch for GitHub Workflow by @apupier in [#1204](https://github.com/apache/arrow-java/pull/1204)
* GH-1232: don't drop TLS for endpoint locations in getStreams by @Arawoof06 in [#1233](https://github.com/apache/arrow-java/pull/1233)

#### New Features and Enhancements
* GH-1063: Add is_update field to ActionCreatePreparedStatementResult by @ennuite in [#1064](https://github.com/apache/arrow-java/pull/1064)
* GH-1188: Reduce test workflow waste by @xborder in [#1189](https://github.com/apache/arrow-java/pull/1189)
* GH-577: Use JVM proxy settings in Netty client by @ennuite in [#1027](https://github.com/apache/arrow-java/pull/1027)
* GH-1271: [Flight] Reject port 0 in NettyClientBuilder by @ennuite in [#1282](https://github.com/apache/arrow-java/pull/1282)
* GH-1302: Add support for the arrow.json extension type by @ddupg in [#1303](https://github.com/apache/arrow-java/pull/1303)
* GH-192: Make LZ4 frame compression and decompression at least 10x faster with lz4-java by @andygrove in [#1420](https://github.com/apache/arrow-java/pull/1420)
* MINOR: Bounds check delta dictionary data copy in VectorAppender by @Arawoof06 in [#1364](https://github.com/apache/arrow-java/pull/1364)
* GH-1442: [JDBC] Harden hostnameOverride handling and tests by @jbonofre in [#1443](https://github.com/apache/arrow-java/pull/1443)
* MINOR: Check buffer bounds before writing long decimal values by @robert3005 in [#1444](https://github.com/apache/arrow-java/pull/1444)
* GH-62: Optimize Flight SQL JDBC Statement execution paths by @xborder in [#1090](https://github.com/apache/arrow-java/pull/1090)
* GH-1466: Add an option to fully validate IPC batches when reading them by @jbonofre in [#1467](https://github.com/apache/arrow-java/pull/1467)

**Full Changelog**: [changelog](https://github.com/apache/arrow-java/commits/v19.0.0)

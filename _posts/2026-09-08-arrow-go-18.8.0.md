## Highlights

### Arrow

#### Features

- Added `VariantGet` for efficient path extraction from variant arrays [#1206](https://github.com/apache/arrow-go/pull/1206)
- Added `list_element`, `cumulative_sum`, `cumulative_sum_checked`, and `dictionary_encode` compute functions [#1138](https://github.com/apache/arrow-go/pull/1138),
[#1139](https://github.com/apache/arrow-go/pull/1139), [#1140](https://github.com/apache/arrow-go/pull/1140)
- Added `ValueAsAny` for accessing Arrow array values as native Go values [#1170](https://github.com/apache/arrow-go/pull/1170)
- Strengthened IPC file validation for malformed block framing and lengths [#1097](https://github.com/apache/arrow-go/pull/1097)

#### Bug Fixes
- Fixed a memory leak when calling `Resize(0)` on non-empty builders [#995](https://github.com/apache/arrow-go/pull/995)
- Preserved exact precision when casting strings to Decimal128 and Decimal256 scalars [#1107](https://github.com/apache/arrow-go/pull/1107)

#### Performance Improvements

- Expanded SIMD acceleration for compute arithmetic, comparisons, and filtering on ARM64 and AMD64 [#1265](https://github.com/apache/arrow-go/pull/1265), [#1266](https://github.com/apache/arrow-go/pull/1266),
[#1284](https://github.com/apache/arrow-go/pull/1284), [#1286](https://github.com/apache/arrow-go/pull/1286), [#1287](https://github.com/apache/arrow-go/pull/1287)
- Added SIMD-accelerated packing of boolean slices and validity data into Arrow bitmaps [#1283](https://github.com/apache/arrow-go/pull/1283)

### Parquet

#### Features

- Added read and write support for GeoArrow extension types using Parquet geometry and geography logical types [#960](https://github.com/apache/arrow-go/pull/960),
[#969](https://github.com/apache/arrow-go/pull/969)
- Added codec-aware dictionary cost fallback and per-column writer controls [#1036](https://github.com/apache/arrow-go/pull/1036)

#### Bug Fixes

- Correctly populated Bloom filters from dictionary-encoded values [#1164](https://github.com/apache/arrow-go/pull/1164)
- Rejected decimal values that overflow Parquet INT32 or INT64 columns instead of silently narrowing them [#1122](https://github.com/apache/arrow-go/pull/1122),
[#1161](https://github.com/apache/arrow-go/pull/1161)
- Fixed reading fixed-size lists whose parent values are null [#1099](https://github.com/apache/arrow-go/pull/1099)

#### Performance Improvements

- Added SIMD BYTE_STREAM_SPLIT encoding on ARM64 and AMD64 [#1260](https://github.com/apache/arrow-go/pull/1260)
- Vectorized fixed-width dictionary materialization on AVX2 systems [#1269](https://github.com/apache/arrow-go/pull/1269)
- Reduced copying when writing binary and fixed-size binary Arrow values to Parquet [#1262](https://github.com/apache/arrow-go/pull/1262), [#1263](https://github.com/apache/arrow-go/pull/1263)

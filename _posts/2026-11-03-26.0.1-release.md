The Apache Arrow team is pleased to announce the 26.0.1 release.
The 26.0.1 release is mostly a security bugfix release that includes [**20 resolved issues**][1]
on [**24 distinct commits**][2] from [**14 distinct contributors**][2].

See the [Install Page](https://arrow.apache.org/install/) to
learn how to get the libraries for your platform.

The release notes below are not exhaustive and only expose selected highlights
of the release. Many other bugfixes and improvements have been made: we refer
you to the [complete changelog][3].

This release includes **a security fix** where we have bumped the bundled version for
Brotli which was affected by ([CVE-2026-111497](https://www.cve.org/CVERecord?id=CVE-2026-111497)).
The Brotli CVE affected PyArrow wheels and R binaries.

## C++ notes

* Fix parquet treating unknown compression codec as uncompressed
  ([GH-53518](https://github.com/apache/arrow/issues/53518)).
* Fix possibly reading out of bounds a MapArray on invalid IPC stream/file
  ([GH-54936](https://github.com/apache/arrow/issues/54936)).
* Fix out of bounds read in `round(int, precision)` for the most negative precision on Gandiva
  ([GH-50544](https://github.com/apache/arrow/issues/50544)).
* Fix Content Defined Chunking resetting its state on every row group
  ([GH-51684](https://github.com/apache/arrow/issues/51684)).

## Python notes

* Bump brotli version on PyArrow ([GH-55165](https://github.com/apache/arrow/issues/55165))
  to avoid bundling version with [CVE-2026-111497](https://www.cve.org/CVERecord?id=CVE-2026-111497).
* Fix `pyarrow.compute.indices_nonzero` segfaulting on a ChunkedArray with zero chunks
  ([GH-51018](https://github.com/apache/arrow/issues/51018)).

## R notes

* Fix CRAN build for macOS were [simdjson](https://github.com/simdjson/simdjson) was failing
  to build with the macOS 11 SDK ([GH-55267](https://github.com/apache/arrow/issues/55267)).
* Bump brotli version on R Windows builds ([GH-55165](https://github.com/apache/arrow/issues/55165))
  to avoid bundling version with [CVE-2026-111497](https://www.cve.org/CVERecord?id=CVE-2026-111497).

## Linux packaging notes

* Add missing opentelemetry dependency to libarrow2600 on Debian packages ([GH-55112](https://github.com/apache/arrow/issues/55112)).

## Other modules and languages

No general changes were made to the other libraries or languages.
